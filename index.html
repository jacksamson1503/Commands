Package Management Commands

CommandUse Case
sudo apt updateRefresh package repository list
sudo apt upgrade -yUpgrade installed packages
sudo apt install package_name -yInstall package
sudo apt remove package_name -yRemove installed package
sudo apt autoremove -yRemove unused packages
apt list --installedList installed packages
apt search package_nameSearch package
dpkg -i package.debInstall local .deb package
